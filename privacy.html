プライバシーポリシー

最終更新日：2026年9月15日

「夜ふかし紙芝居アップローダー」（以下「本ツール」）は、YouTubeチャンネル「夜ふかし紙芝居」の運営者が自分の動画を自分のチャンネルへ投稿するためだけに使う内部ツールです。本ツールでの情報の扱いを以下に定めます。

1. 取得する情報

本ツールは、Google の OAuth 認証を通じて、運営者の許可のもとで次の権限だけを使います。

  • youtube.upload：運営者のチャンネルに動画をアップロードするため
  • youtube.readonly：投稿先が運営者のチャンネルであることを確認するため、チャンネル名を読み取るため

氏名、メールアドレス、視聴履歴、コメント、他のユーザーの情報は取得しません。

2. 情報の使い道

取得した権限とデータは、運営者自身のチャンネルへの動画アップロードと、投稿先チャンネルの確認にだけ使います。広告、分析、プロファイリング、その他の目的には使いません。

3. 保存場所と保存期間

認証トークンは運営者のパソコン内にだけ保存し、外部のサーバーには送信・保存しません。運営者が連携を解除するか本ツールの使用をやめた時点で削除します。

4. 第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。ただし、動画のアップロードのために Google（YouTube）へ送信することを除きます。

5. Google API サービスの利用

本ツールは YouTube API サービスを利用しています。本ツールを利用することは、YouTube 利用規約に同意したものとみなされます。Google におけるデータの取り扱いについては、Google プライバシーポリシーをご覧ください。本ツールによる Google API から取得した情報の使用は、Limited Use の要件を含む Google API Services User Data Policy に従います。

6. 連携の解除

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本ツールへのアクセス権を取り消せます。
