夜ふかし紙芝居アップローダー

YouTubeチャンネル「夜ふかし紙芝居」の運営者が、自分で制作したショート動画を自分のチャンネルへ投稿するためだけに使う内部ツールです。

このツールがすること

  • 運営者のパソコンで制作した動画ファイルを、YouTube Data API を使って運営者自身のチャンネルにアップロードします。
  • アップロード時に、タイトル・説明文・タグ・公開設定（非公開または予約公開）を設定します。
  • 投稿先が運営者のチャンネルであることを確認するため、チャンネル名を読み取ります。

このツールがしないこと

  • 運営者以外のユーザーは利用できません。一般公開や配布はしていません。
  • 他人のチャンネルや動画の閲覧・編集・削除、コメントの取得や投稿、視聴データの収集は行いません。
